# Steampunk_KSP_Parts
Steampunk parts pack for Kerbal Space Program

Currently all parts are decorative. In the future there will be a custom plugin to handle steam simulation.

Requires Resurfaced/Technicolor and its prerequisites. https://github.com/Tantares/Resurfaced/releases/

Recommended to play with ReStock PBR. https://github.com/PorktoberRevolution/ReStockPBR/releases

Currently includes:
* 1.25m boiler parts in 1m, 2m, and 3m lengths. (full TC support)
* Smokebox Door decorative endcap. (full TC support)
